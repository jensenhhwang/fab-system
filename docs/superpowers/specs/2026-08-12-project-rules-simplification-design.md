# 프로젝트 규칙 단순화 설계

## 목표

프로젝트 규칙의 원본을 `RULES.md` 한 곳으로 모으고, Codex와 Claude Code가 각자의 공식 탐색 규칙을 통해 동일한 내용을 읽게 한다. 크리·패브·엑스는 사용자가 명시적으로 요청한 경우에만 호출하며, 일반 기능 요청에서는 자동으로 실행하지 않는다.

## 현재 문제

- 루트 `AGENTS.md`가 Next.js 주의사항과 3인 기획팀 자동 호출 절차를 함께 담고 있다.
- 일반적인 기능 표현만으로 세 서브에이전트가 순차 호출되어 작은 작업도 지연된다.
- `.claude/agents/`에 에이전트 정의가 있지만, 프로젝트 공통 규칙을 주제별로 관리하는 `.claude/rules/`는 없다.
- `AGENTS.md`를 완전히 삭제하면 Codex가 프로젝트 규칙을 자동 발견할 진입점도 사라진다.

## 파일 구조

```text
RULES.md
AGENTS.md
.claude/
  agents/
    cree.md
    fab.md
    x.md
  rules/
    project.md -> ../../RULES.md
```

### `RULES.md`

프로젝트 규칙의 단일 원본이다. 다음 규칙만 둔다.

1. 이 저장소의 Next.js 버전은 학습 데이터와 다를 수 있으므로 코드를 작성하기 전에 `node_modules/next/dist/docs/`의 관련 문서를 읽는다.
2. 운영·시뮬레이션 시간은 공통 Twin 운영시계를 사용하고 기본 배속을 `24×`로 계산한다.
3. `createdAt`, 승인 시각, 사용자 조치, 감사 로그처럼 실제 발생 사실을 기록하는 시각은 벽시계 `recordedAt` 계열로 유지하며 가속하지 않는다.
4. 생산 진행, 자재 소모, 발주 ETA, 최종테스트, 자동출하, 계약 기간 집계처럼 모델 운영에 속한 시간만 `실제 경과시간 × 24`로 계산한다.
5. 크리·패브·엑스와 그 밖의 서브에이전트는 사용자가 이름을 지정하거나 "3인 기획팀 검토"처럼 명시적으로 요청한 경우에만 호출한다.

### `AGENTS.md`

Codex가 자동 발견하는 최소 진입점이다. 상세 규칙을 중복하지 않고 다음 두 요구만 전달한다.

```md
Before working in this repository, read and follow `RULES.md`.
Do not invoke subagents unless the user explicitly requests them.
```

두 번째 문장은 `RULES.md`를 읽기 전에도 자동 서브에이전트 호출이 일어나지 않게 하는 안전장치다.

### `.claude/rules/project.md`

Claude Code가 자동 발견하는 프로젝트 규칙 파일이다. 별도 사본을 만들지 않고 `../../RULES.md`를 가리키는 상대 심볼릭 링크로 둔다. 프로젝트가 이동해도 저장소 내부 상대경로는 유지되며, 규칙 수정이 한 파일에만 발생한다.

### `.claude/agents/*.md`

기존 크리·패브·엑스 정의는 삭제하지 않는다. 자동 발동 조건만 없애고, 사용자가 필요할 때 직접 요청해 재사용할 수 있게 유지한다.

## 동작 원칙

- "기능을 만들자", "개선하자", 새 페이지 요청만으로 서브에이전트를 호출하지 않는다.
- "크리에게 검토시켜줘", "패브와 엑스까지 확인해줘", "3인 기획팀 불러줘"처럼 호출 의도가 명시된 경우에만 요청 범위의 에이전트를 사용한다.
- 시간 관련 신규 기능은 독자적인 `new Date()` 기반 운영 계산이나 제품별 임의 배속을 만들지 않고 공통 Twin 운영시계에 연결한다.
- 벽시계와 운영시계를 필드명과 화면 표기에서 구분한다.

## 오류와 호환성

- Codex는 `RULES.md` 자체를 자동 탐색하지 않으므로 `AGENTS.md`를 삭제하지 않는다.
- Claude Code용 링크가 깨지면 규칙이 로드되지 않으므로 상대 대상이 정확히 `../../RULES.md`인지 검증한다.
- 심볼릭 링크를 지원하지 않는 환경에서는 `.claude/rules/project.md`에 `RULES.md`를 읽으라는 최소 지시를 두는 방식으로 대체하되, 규칙 본문을 복제하지 않는다.

## 검증

1. `AGENTS.md`에 자동 발동 키워드와 3인 순차 호출 절차가 남아 있지 않은지 검색한다.
2. `RULES.md`에 Next.js 문서 확인, 24× 운영시간, 벽시계 예외, 명시적 서브에이전트 호출 규칙이 모두 존재하는지 확인한다.
3. `.claude/rules/project.md`가 `../../RULES.md`를 가리키는 심볼릭 링크인지 확인한다.
4. `.claude/agents/cree.md`, `fab.md`, `x.md`가 그대로 존재하는지 확인한다.
5. 일반 기능 요청과 명시적 3인 검토 요청의 기대 동작을 문서 기준으로 대조한다.

## 범위 제외

- 크리·패브·엑스 에이전트 프롬프트 자체의 변경
- 전역 `~/.codex/AGENTS.md` 또는 `~/.claude/rules/` 변경
- 24× Twin 운영시계의 실제 코드 구현
- 다른 저장소의 규칙 구조 변경
